About This Project

Supermarket Sales Analysis is a data analytics project developed to understand sales performance, revenue and profit.

This dashboard displays sales summaries, supermarket product images and interactive charts to help users understand business performance.

Technologies Used: Python, Pandas, Flask, HTML, CSS, JavaScript and Chart.js.
